# Base DNS Server
This is base of the Core of DNS Server, just for experimenting, further developing.


## 🛠️ Compile & run
```bash
gcc main.c -o dnsserver && ./dnsserver
```

## 🧑🏻‍💻 Test
```bash
dig some.domain.com @127.0.0.1 +tcp
```
